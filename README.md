# 🚀 Crack SQL

> **Think Like a Data Engineer, Not Just a SQL Developer**

Crack SQL is a mobile-first SQL learning platform that helps learners develop business thinking before writing SQL queries.

Unlike traditional SQL practice websites, Crack SQL evaluates the learner's thought process, provides guided pseudo logic, and then reveals the SQL solution.

---

# 🎯 Vision

Build the world's best SQL learning platform that teaches **business thinking**, **problem-solving**, and **real-world SQL skills**.
